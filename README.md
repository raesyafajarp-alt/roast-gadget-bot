A one-line roast of the wireless earbuds, written for make.fun's
**One-Line Roast: The Gadget You Use Every Day** bounty. The program
writes a single line of at most 200 characters to `/output/entry.txt`.

## The roast

> My earbuds die one at a time, taking turns ghosting me mid-song — I paid for stereo and got a one-ear monologue.

112 characters, one line. The angle is not the stock joke about a phone
battery dying at four in the afternoon: it roasts a real behaviour —
wireless earbuds always lose one side first, right in the middle of a
song — and lands the sting on the price. You paid for stereo sound and
ended up with a one-ear monologue.

## Run it

```sh
python3 main.py
```

Python 3, standard library only, no network. Deterministic: every run
writes the same bytes. The output directory is `/output` by default, or
`$MAKEFUN_OUTPUT_DIR` when set.
